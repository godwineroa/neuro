HOW TO ADD YOUR PHOTOS (5 total)
=================================
Drop your photos in THIS folder and name them exactly:

  IMAGE_PLACEHOLDER_01.jpg
  IMAGE_PLACEHOLDER_02.jpg
  ...
  IMAGE_PLACEHOLDER_05.jpg

Tips:
- JPG is expected by default. If you use .png, open script.js and change
  IMAGE_EXT = "jpg"  to  IMAGE_EXT = "png"  (near the top of the file).
- Any size works, but photos around 800-1200px wide load fastest.
- To change the caption under each photo, edit the PHOTO_CAPTIONS list
  near the top of script.js.
